# One Tab Only

Chrome extension that keeps selected websites limited to one open tab.

## Install

1. Open `chrome://extensions/`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select this project folder.

## Use

1. Open a site.
2. Click the extension icon.
3. Click Limit this domain.

When you open a duplicate watched domain, choose whether to switch to the existing tab, replace it, close it and continue, or open anyway.

## Permissions

- `tabs`: detect and manage duplicate tabs
- `storage`: save watched domains and settings
- `webNavigation`: react to URL changes
